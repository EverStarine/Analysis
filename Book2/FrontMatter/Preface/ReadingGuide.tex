\noindent\textbf{第一卷的有限回查点。}
基本积分与 \(L^p\) 理论贯穿本卷，较专门的输入只在相应位置需要。
\begin{itemize}
\item 进入\chapref{b2:ch:10}前，补读第一卷定理 8.5.5 的紧自伴谱定理，以及命题 21.4.1 的区间 Sobolev 绝对连续代表。前者在第一卷属于选读，在本章却是 Green 逆算子谱展开的必需工具。Green 逆把边值问题转为紧算子的特征展开；未准备好谱论时，可以先读全空间波动方程与热核，暂缓区间谱展开。
\item \chapref{b2:ch:14}使用第一卷定理 9.4.7 的弱收敛子列、定理 9.5.2 的闭凸集弱闭性，以及定理 9.5.8--9.5.9 的凸泛函弱下半连续性与直接方法。用于梯度能量时还须核对 \(1<p<\infty\) 的自反性和零边界 Poincaré 不等式，这些条件共同确定有界序列可以取得哪一种收敛子列。
\item \chapref{b2:ch:15}使用第一卷定理 8.4.7 的 Hilbert 空间 Riesz 表示，并在 \(H_0^1(\Omega)\) 中求弱解。第一卷定义 22.2.1 以光滑紧支集函数的闭包规定零边界条件；在有界 Lipschitz 区域上，才按第一卷定理 23.1.6 解释为零迹。强制性所需的 Poincaré 不等式及有关嵌入见第一卷第二十四章。
\item \chapref{b2:ch:16}沿用上述能量空间，按所用估计回查 Sobolev 不等式、截断与局部坐标下的弱导数。内部估计不要求整个边界光滑；全局二阶 Dirichlet 估计则使用正文列明的 \(C^{1,1}\) 边界和 Lipschitz 系数，两者不能混同。
\item \chapref{b2:ch:15}末的 Fredholm 选读部分另用第一卷附录 C 的紧扰动理论及推论 25.2.6 的零边界紧嵌入。\appref{b2:app:D}的一般非负自伴算子视角还需要无界自伴谱定理与 Borel 函数演算，其范围大于第一卷的紧自伴谱定理。这一谱观点把具体的热算子推广为一般算子的时间演化，附录给出所用谱定理的来源。
\end{itemize}

\noindent\textbf{本卷所需的复分析工具。}
\secref{b2:sec:0402}通过特殊三线估计，把 Fourier 变换的两个端点界连接起来。\secref{b2:sec:1704}处理一般解析插值时，使用全纯函数的局部光滑性、Cauchy--Riemann 方程及实虚部调和，并回查\cref{b2:cor:13-boundary-maximum}的调和最大值原理。沿调和分析路线阅读时，可在此回查\secref{b2:sec:1301}的调和最大值原理。

\ProseParagraphBreak
选读的\chapref{b2:ch:20}另用局部 Cauchy 公式、唯一性和 Cauchy 导数估计。即使跳过该章，进入普通正文\secref{b2:sec:2304}前也须掌握局部 Cauchy 公式及其局部一致极限、幂级数和唯一性推论；该节会回忆这些事实，再构造所需的复 Gamma 函数和分布解析族。局部 Cauchy 公式使参数的求导与极限有了统一工具，尤其适合处理解析函数列和分布配对。

\noindent\textbf{课程可以怎样取舍？}
\begin{itemize}
\item Fourier 基础课程以第二编的级数、反演、Plancherel、插值和分布为主体。\chapref{b2:ch:ode}可以暂缓，\chapref{b2:ch:approximation}按最佳逼近与误差估计的学习需要选读。\chapref{b2:ch:05}的 Hermite 专题及\chapref{b2:ch:06}相关补例可先略过，进入\appref{b2:app:B}前补读；Poisson 求和、采样、周期热核和 theta 的算术联系可按用途选择。
\item 经典与弱解 PDE 课程先补齐\chapref{b2:ch:ode}的存在唯一、可微流与连续系数线性系统，再从第二编所需工具进入第三编的经典方程，随后学习第四编的变分、弱解与正则性。区间谱理论按前述方式准备；\appref{b2:app:D}接热方程，\appref{b2:app:H}接椭圆弱解。直接法通过极小化构造解，双线性型处理非对称方程，正则性再研究这些解的导数与连续性。
\item 实变调和分析课程从第二编进入\chapref{b2:ch:17}至\chapref{b2:ch:19}，再读\chapref{b2:ch:22}，并按上文补齐调和最大值原理。非齐次分解及 \(F^s_{p,2}\) 的最小定义放在\secref{b2:sec:1904}，一般 Besov、Triebel--Lizorkin 选读节可以暂缓。接着可在\chapref{b2:ch:22}学习乘子，再到\chapref{b2:ch:21}研究振荡积分；\chapref{b2:ch:20}的测不准原理可按兴趣选读。
\item 振荡与限制课程在上述调和工具之后读\chapref{b2:ch:21}，按需补\appref{b2:app:A}的径向 Fourier、Bessel 渐近和幂权核公式，再读\chapref{b2:ch:23}与\chapref{b2:ch:24}，最后选读\chapref{b2:ch:25}。\chapref{b2:ch:23}的解析构造须先补足前述局部复分析；\appref{b2:app:E}的色散方程与\appref{b2:app:G}的微局部方法是进一步的不同方向。
\end{itemize}
