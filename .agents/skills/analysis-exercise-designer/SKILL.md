# 分析学习题设计

## 先读本章，再确定训练目标

本 skill 安装在项目 `.agents/skills/analysis-exercise-designer/`；从该目录向上三级是项目根目录。若工作目录不同，先定位同时含 `Book1/` 和 `Shared/Preamble.tex` 的项目，不猜绝对路径。

先阅读根目录现行[写作规范](../../../写作规范.md)的章节完成度、习题与文献条款，以及[工作流程说明](../../../工作流程说明.md)的初次撰写和连续写作规定；排版取自[格式规范](../../../格式规范.md)。这些文件是单一真源，不将本 skill 中的例子或旧日期当作更新后的规则。

读取目标 `ChapterNN.tex` 的 `learninggoals`、`chapterguide`、`chaptersummary`、现有习题和实际输入的节文件。题目限定到本章已经建立的工具；需要前章结果时核对稳定标签、假设与版本。读者先修知识与书中已证明结果分开说明，未来章节的预告不充当前提。

- 请求只设计候选题：交付候选题与解答，不直接改教材。
- 请求补写、替换或修改：在授权的章节中实施，保留其他题和已有稳定标签。
- 请求审查：指出具体题目与解答的问题，避免自动启动本章乃至全卷正式审稿。
- 用户规定题量、难度、仅给提示或特定来源时，以该要求定界；发现题目本身不可解或假设矛盾时，说明并给出最小修正方案。

## 用任务差异安排题目

将每道拟选题对应到一个明确训练动作，例如“检查 Fubini 条件”“构造非一致可积族”“解释端点估计为何失效”。候选较多时，在任务临时记录中用简表写明：目标、所用前置工具、相对正文新增的推理、难度、解答状态和来源；少量补题不强制另建表。

先比较正文与已有习题，再选有实质增量的题：改变假设、构造反例、寻找最优常数、连接两个工具，或完成不承担正文主线的推导。不要只更换字母、换成具体数值后仍逐字复现定理证明。正文中心构造尚缺的关键步骤应作为正文问题指出，不能通过移入习题假装主线完整。

全章选题参考项目现行的基础核验—反例/构造—综合证明层次和软性数量建议；不按层次机械各填相同道数，不为满足数量重复一行套用题。第七章 `Book1/Part01/Chapter07/Chapter07.tex` 可作为目标、来源注释与解答的本地样例；每次只读相关段落，不复制其题组到无关章节。

分析学中特别容易误判的训练内容与核验方法见[设计与解答核验](references/design-checks.md)，涉及相应题型时阅读。

## 解答先于题目定稿

独立完成每道候选题，确认所有题设均有明确解释，并且所需技术处在目标读者可达范围。不要先拟一个看似合理的结论，再让解答迎合它。构造题验证对象确实满足全部假设；反例分别证明“满足被保留的假设”和“违反目标结论”。

完整解答使用项目 `solution` 环境，展开新增的关键论证。用户只要提示时明确标为“提示”，不能称完整解答；可在任务临时记录中保留验证思路，不擅自把全解加入学生版。符号计算或数值试验可辅助核对积分、极限与常数，但不能替代一般命题的证明。有限采样没有发现反例，不意味着命题成立。

来源信息以已读到的实际版本为准。复用已有 `Shared/References.bib` 中的 key，并核对 `参考文献原文件/来源记录.md`；只核实目录时不得编造原题编号、页码或“已阅读全文”。改编题的源码注释记录来源 key、所读章节/页码/题号及实质改编；自拟题如实记“自拟”，不要杜撰来源。若来源不可核验，保留为待核候选，或改为可以独立论证且诚实标注的自拟题。

## 接入本项目

- 先定位该章已有的 `\BookExercises`。每章只保留一个入口，不另加 `\section*{习题}` 或重复书签。
- 用 `exercise` 环境和未冲突的 `bN:ex:...` 标签；显示编号由共享计数器产生，不手写题号、不重编号已有标签。
- 接续现有的解答或提示排版。若增加列表项，遵循项目标签规则；行内用 `\(...\)`，展示公式遵循现行编号原则。
- 改变术语主称、正文定理或共享宏不属于一般补题动作；涉及这些变化时先说明实际需要，并依据当前任务授权处理。
- 实际修改后检查新增标签、输入位置、解答配对和受影响引用，按现行流程构建目标卷；可调用同项目 `analysis-book-build-check`。一次增量检查后继续推进，不为补题反复进行全卷视觉验收。
- 习题设计与初稿自检不增加正式审核轮数，不据此把章节登记为定稿。更新源码、审核状态和发布 PDF 各遵循用户当前授权与项目流程。

交付说明聚焦题目覆盖的目标、实质增量、解答或提示状态、已核实的来源，以及实际完成的验证。未做内容证明核验或编译时分别注明，避免笼统报告“全部通过”。
