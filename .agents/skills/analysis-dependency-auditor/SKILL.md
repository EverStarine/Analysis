# 分析学证明依赖审计

## 定位与范围

本 skill 属于当前《分析学》文件夹。安装位置为 `.agents/skills/analysis-dependency-auditor/`；从这里上溯到同时含 `Book1/Book1.tex`、`Book2/Book2.tex`、`Book3/Book3.tex`、`Shared/` 的项目根，或使用用户指定并核对过的根目录。不要把当前任务的工作目录当成教材根目录。

先读项目现行 `工作流程说明.md` 第 2、3、6、9 节、`写作规范.md` 第 2.1、4、9 节与 `跨卷引用表.md`；定稿任务另读 `审核进度.md` 的当前规则。以本轮用户请求确定卷、章、节或稳定标签，核对真实输入链与已有未提交改动。

连续写作期间只检查涉及的陈述、明显逻辑断点及其直接调用处。用户要求专项或正式数学审核时再深入追踪证明链；不因本 skill 被选中自动启动全书审稿、编译、Git 同步或更新审稿轮数。

## 两层核对

1. **源码候选定位。** 用下方只读脚本检索有效输入链中的标签、显式引用、反向引用和纯文字指向。源码位置、稳定标签和内容概要是主键；页码和显示编号须从当前构建核实。脚本结果只是语法候选，尤其不能把 `ref` 关系直接称为证明依赖。
2. **逐项读证明。** 对当前中心结论记录“所需结果及版本—精确假设—本处满足假设的依据—实际调用步骤—文件/行/标签”。检查定义先于使用，以及良定义、可数过程、局部到整体、极限交换、唯一性和零测集等本证明真正涉及的桥梁。反向引用只给出受影响位置；读取这些位置后才判定是否需改动。

将关系区分为实际证明调用、定义/记号依赖、阅读导航、前向预告、外部先修和待判定。前向位置本身不代表循环；循环须由已经确认的语义依赖链形成。凡预告参与当前证明，应指出具体调用和缺失前置结果；只有文本证据不足时保留待判定。

遇到同名定理的不同版本，逐项比较对象、可测域、完备性、有限性/σ-有限性、正则性与结论强弱，按当前问题选择相关项。例如当前第一卷第七章换元路线以第六章 Radon–Nikodym 定理识别密度；核查时应读现有第七章导语及 `Section0705.tex`，确认是否实际调用后面才建立的微分定理或面积公式，不把这个历史路线变成不可更改的定理要求。

## 只读辅助脚本

用现有 Python 3 运行，无额外依赖；`<project-root>` 是核实后的项目根，`<skill-dir>` 是本 skill 目录。脚本只向标准输出打印 JSON，既不改正文也不回写台账。

```text
python "<skill-dir>/scripts/dependency_inventory.py" --root "<project-root>" --scope Book1/Part01/Chapter07
python "<skill-dir>/scripts/dependency_inventory.py" --root "<project-root>" --label b1:thm:radon-nikodym
```

`--scope` 和 `--label` 均可重复；`--scope` 选择文件/目录及它定义的标签的直接反向引用，`--label` 查指定标签的定义与全部直接引用（也可查已删除但仍被引用的标签）。仅在全书静态核对有必要时使用 `--all`。安装后可省略 `--root`，脚本会从自身路径查找项目；暂存或测试时应显式传根目录。

输出包含有效输入文件、输入链异常、带上下文的定义/引用、同卷重复标签候选、未解析或跨卷普通引用候选、同卷源码顺序，以及文字引用候选。各卷入口独立展开，输入路径优先相对于卷目录解释；不扫描 `tmp/`、`.git/` 或输入链外的旧稿。`--max-text-candidates` 限制文字候选数量，截断数会明确报告。

这是轻量 TeX 扫描器：处理常见有花括号的输入和引用、注释、常用 verbatim 环境，以及项目 `BookPart`、`OptionalChapter/Section/Subsection`、`BookAppendixPart` 的标签参数；不展开其他宏、条件分支、动态文件名或外部辅助标签，不代替 TeX 编译。纯文字指向可能漏检；上下文的“最近标签”不是已确定的定理归属。遇到输入链问题先说明覆盖范围，不能据空输出宣称依赖无误。

## 交付与落盘

反馈优先给出可操作的数学问题及位置：被调用结果、当前缺失的条件/步骤、影响哪些直接使用处；将已确认问题与候选分开，说明实际读过的范围。必要时给一个小表展示证明链，不生成庞大全书关系图。

纯审核只交付结论；修订任务在授权范围内修正文和相关记录。新增跨卷引用时按 `跨卷引用表.md` 登记双方文件、最近标签、概要、当前编号和方向，三卷独立 PDF 不使用普通内部链接冒充跨卷链接。横向依赖核对不计入逐章审稿轮数；有未解决核心疑点时遵循当前 `coreverification` 约定，不自行标为定稿。
