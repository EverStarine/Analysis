# 术语与索引核对

本技能安装于项目 `.agents/skills/analysis-term-index-auditor/`；从技能目录向上三级即项目根目录。以本次打开的项目为准，不依赖固定盘符。根目录 Markdown 是规范真源，不在技能内复制另一份术语表。

先阅读根目录 [术语规范.md](../../../术语规范.md)、[格式规范.md](../../../格式规范.md) 的相关规定，以及 [工作流程说明.md](../../../工作流程说明.md) 的检查范围要求；核对 [Shared/Preamble.tex](../../../Shared/Preamble.tex) 中当前宏定义。用户只要求检查时，输出证据与修正建议；要求修改时实施相应改动。连续写作期只检查本章新增或修改术语及受影响的相关位置，全面横向审计按用户要求启动。

## 语义先于替换

- 从正文首次正式定义、周围假设和规范记录识别概念。分别记录主称、原文、适用域、异名及来源、定义或约定的位置、待核定状态；只为本次任务生成临时核对表，不建立与根规范并行的长期登记簿。
- 同一词面不保证同一概念。对照测试函数类、有限性、拓扑、定义域、正负号、归一化和标量域等实际条件。重点参考规范中淡收敛与弱收敛、内积线性变量、Radon 测度、密度、可整流性等已注明的区别；不把这些例子当成固定不变的完整清单。
- 首次定义按各卷的真实输入链和上下文判定。引言预告、文献比较、脚注异名不自动成为定义；文件字典序、第一次字符串命中和首次使用索引宏均不能独立证明定义先后。
- 正式中文来源支撑主称与异名。只读到目录时，证据仅限名称和位置，不声称核验了定义或证明。已允许暂用的描述性名称保留“待核定”，不自行升级为正式主称。
- 修改已核定主称时检索受影响卷的标题、正文、索引与相关引用显示文字，保留稳定标签。未核定旧称不自动新增为异名；纲要中的消歧占位按现行规范处理，不随正文翻译自动改写。

## 宏与三类索引

当前共享宏接口如下；实际定义变动时以 `Shared/Preamble.tex` 为准。

```tex
\term[拼音键]{中文主称}[原文]
\term*[拼音键]{人名与结果类别}[原文]
\termidx[拼音键]{中文异名}
\foreignidx[排序键]{原文或异名}
\symidx{\(\lVert f\rVert_1\)：说明}
```

`term` 首个排序键与末尾原文均可省略；星号只隐藏正文原文，仍登记中外文索引，不能当成漏收外文。判断简单人名定理是否用星号时阅读规范，不按英文后缀自动转换。原文是实际原语言。首次说明的异名与出处应能定位到同页；后文通常只用主称，不重复粗体引入。具名定理的环境可选标题只写名称，不嵌术语或索引宏。

中文索引核对显示主称与拼音键，特别留意同词不同键、同键不同词、多音字与专名；缺显式键只是检查候选，不一概视为错误。外文索引核对原文、拼写、必要异名及排序。符号索引每个符号一个主条目，链接到首次定义或明确约定，按编译时首次登记顺序排列；复用字形须先辨明是否同一个符号对象。局部临时对象通常不收录。

索引参数同时受 TeX 和 makeindex 语法约束。检查裸 `|`、`@`、`!` 等是否意外成为处理符；范数优先按规范用 `\lVert`、`\rVert`。不能只凭出现特殊字符判错，须结合转义、索引层级和实际 `.ilg`。不要用全局文本替换处理术语、数学星号或嵌套宏。

## 可复现定位

需要批量清点时使用只读标准库脚本，路径相对于 `--root`；`--scope` 可重复指定节文件或目录：

```powershell
python .agents/skills/analysis-term-index-auditor/scripts/inventory_terms.py --root . --scope Book1/Part02/Chapter12
```

脚本向标准输出写 JSON，不改源码、不编译、不安装包。它识别上述四种宏的普通字面调用、星号、可选参数、嵌套花括号及 TeX 注释，保留文件与行号；汇总排序键冲突、重复引入及符号重复等候选。`--scope .` 仅在确需全项目清点时使用。它不展开宏、不执行条件分支、不跟踪输入顺序，不核验拼音正确性或数学语义；直接 `\index` 和动态生成条目需另查。

对每个候选回到上下文确认，以“已确认问题 / 待核定 / 合理差异”区分结果，列出位置、规范或定义依据和最小处理方案。改动正文索引后按项目构建流程检查本卷；共享宏改动影响三卷。读取已有产物时核对来源时间，不能把旧 `.ind` 当成修订已生效。正式索引验收要求各类 `.ilg` 的拒收与警告均为零，并在相关 `.idx`、`.ind` 和 PDF 位置核实条目；仅完成源码清点就如实报告源码范围，不宣称排版或链接已通过。
