\chapter{Lebesgue 测度}
\label{b1:ch:03}
% 本章摘要（不计入编号）
\begin{chapterabstract}
本章在 \(\mathbb R^d\) 上构造 Lebesgue 测度，并说明它如何把长度、面积和体积统一为同一对象。核心步骤是以长方体覆盖定义外测度、用 Carathéodory 条件得到可测集，再证明这一测度具有正则性及欧氏变换下的自然不变性。
\end{chapterabstract}

% 本章目标（不计入编号）
\begin{learninggoals}
\begin{itemize}
  \item 能用可数长方体覆盖写出 Lebesgue 外测度的定义；
  \item 能说明 Borel 集、零测集与 Lebesgue \(\sigma\)-代数之间的关系；
  \item 能使用外正则性、内正则性和 Borel 逼近；
  \item 能陈述平移、正交变换与线性变换下的测度公式。
\end{itemize}
\end{learninggoals}

\begin{chapterguide}
第三章把第二章的抽象延拓机制落实到欧氏空间。读者可先把 \(d=1\) 时的区间长度作为直观模型；证明中真正起作用的是可数覆盖、可数基和 \(\sigma\)-有限性，而不是一维的特殊图形。
\end{chapterguide}

% 本章小结（不计入编号）
\begin{chaptersummary}
Lebesgue 外测度以可数长方体覆盖的总体积下确界定义。Carathéodory 条件给出 Lebesgue \(\sigma\)-代数与完备的 Lebesgue 测度；它是 Borel 测度的完备化。外、内正则性分别允许用开集和紧集逼近可测集，平移、正交与线性变换则按行列式刻画体积的变化。
\end{chaptersummary}

\section*{习题}
\begin{exercise}\label{b1:ex:0301}
证明任意可数子集 \(D\subseteq\mathbb R^d\) 都是 Lebesgue 零测集。
\end{exercise}
\begin{solution}
逐点用体积小于 \(\varepsilon2^{-n}\) 的立方体覆盖，合并后得到总覆盖体积小于 \(\varepsilon\)。令 \(\varepsilon\downarrow0\)。
\end{solution}
\begin{exercise}\label{b1:ex:0302}
设 \(E\in\mathcal L^d\)、\(a\in\mathbb R^d\)。用 \cref{b1:thm:translation-invariance} 证明 \(m(E-a)=m(E)\)。
\end{exercise}
\begin{solution}
将平移不变性应用于集合 \(E-a\) 和向量 \(a\)，即可得到 \(m(E)=m((E-a)+a)=m(E-a)\)。
\end{solution}
\begin{exercise}\label{b1:ex:0303}
若 \(E\in\mathcal L^d\) 且 \(m(E)<\infty\)，证明对每个 \(\varepsilon>0\) 存在紧集 \(K\) 与开集 \(G\)，使 \(K\subseteq E\subseteq G\) 且 \(m(G\setminus K)<\varepsilon\)。
\end{exercise}
\begin{solution}
分别使用 \cref{b1:thm:inner-regular} 和 \cref{b1:thm:outer-regular}，使 \(m(E\setminus K)<\varepsilon/2\)、\(m(G\setminus E)<\varepsilon/2\)，再以不交并相加。
\end{solution}
